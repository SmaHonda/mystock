# 台股持股管理系統

純前端的台股持股管理工具，資料存在瀏覽器 LocalStorage，可匯出 JSON 備份。

## 功能

- ✅ 手動輸入持股（股票代號、名稱、買入價、股數、日期）
- ✅ 多券商帳戶分開管理
- ✅ 配股配息紀錄（現金股利 / 股票股利分開記錄）
- ✅ 雙重損益計算
  - 不含降成本：市值 - 總成本
  - 含降成本：市值 - 總成本 + 累計現金股利
- ✅ 總覽頁面：總成本、市值、累計股利、損益、報酬率
- ✅ 個股詳情：買入紀錄、配股配息明細、降成本效果
- ✅ 本地儲存 + JSON 備份 / 還原

## 使用方式

1. 下載或 clone 專案
2. 用瀏覽器開啟 `index.html`
3. 開始記錄你的持股

## 備份

- 點擊「匯出備份」下載 JSON 檔
- 點擊「匯入備份」還原資料
- 建議定期備份，避免清除瀏覽器資料導致遺失

## 計算公式

| 項目 | 公式 |
|------|------|
| 總股數 | 買入股數 + 配股股數 |
| 原始均價 | 總成本 ÷ 買入股數 |
| 降成本均價 | (總成本 - 累計現金股利) ÷ 總股數 |
| 損益（原始） | 市值 - 總成本 |
| 損益（降成本） | 市值 - 總成本 + 累計現金股利 |
| 報酬率 | 損益（降成本） ÷ 總成本 × 100% |

## 技術

- 純 HTML / CSS / JavaScript
- 無需後端，無需安裝
- LocalStorage 本地儲存
- 響應式設計，支援手機
